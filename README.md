# Description Changer Bot
Телеграм бот для смены описаний через временной интервал

## Команды
-`/addesc` — добавить описание(/addesc описание к примеру)

-`/setime` — задать интервал обновления(s - секунда , m - минута, h - час)

-`deldesc` — удалить определенное описание по индексу(/deldesc 1 к примеру)

## Настройки
-API_TOKEN — токен вашего бота

-CHANNEL_ID — айди вашего канала(указывать через @ если открытый канал)

-ADMIN_ID — айди админа

## Запуск
```bash
pip install -r requirements.txt
python main.py
